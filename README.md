# ប្រព័ន្ធគ្រប់គ្រងសាលាមត្តេសិក្សាខ្នងក្រពើ

គម្រោងនេះជា Prototype ប្រព័ន្ធគ្រប់គ្រងសាលាមត្តេយ្យ ដែលដំណើរការលើ Browser និងប្រើរចនាប័ទ្មផ្ទាំងគ្រប់គ្រង SaaS ទំនើប។

## មុខងារដែលមាន

- ផ្ទាំងគ្រប់គ្រងជាមួយកាតស្ថិតិ ក្រាហ្វចុះឈ្មោះ សមត្ថភាពថ្នាក់ និងការចុះឈ្មោះថ្មីៗ
- ម៉ឺនុយចំហៀងបង្រួមបាន, Top navigation, Breadcrumb, ការជូនដំណឹង, Profile dropdown និង Quick action
- គ្រប់គ្រងសិស្ស៖ ចុះឈ្មោះ កែប្រែ លុប បង្ហោះរូបថត ស្វែងរក តម្រៀប និងបែងចែកទំព័រ
- បង្កាន់ដៃចុះឈ្មោះសិស្សថ្មីទម្រង់លិខិតផ្លូវការ ដែលអាចបោះពុម្ពលើ A4 មួយសន្លឹកបាន ២ ច្បាប់៖ សម្រាប់សិស្ស និងសម្រាប់គ្រូ
- គ្រប់គ្រងគ្រូ និងចាត់តាំងគ្រូទៅថ្នាក់
- គ្រប់គ្រងថ្នាក់៖ ទាប, មធ្យម, ខ្ពស់
- ឡើងថ្នាក់សិស្សប្រចាំឆ្នាំ និងកំណត់សិស្សថ្នាក់ខ្ពស់ជា បានបញ្ចប់
- បង្កើតវិញ្ញាបនបត្របញ្ចប់ការសិក្សា ជាមួយលេខវិញ្ញាបនបត្រ ថ្ងៃចេញ ត្រាសាលា ហត្ថលេខា និង QR ផ្ទៀងផ្ទាត់
- របាយការណ៍ជាមួយការនាំចេញ CSV និងបោះពុម្ពជា PDF តាម Browser
- តួនាទីអ្នកប្រើ៖ អ្នកគ្រប់គ្រង បុគ្គលិក និងគ្រូបង្រៀន
- គ្រប់គ្រងឆ្នាំសិក្សា
- ការកំណត់សាលា ប្រតិទិន រំលឹកថ្ងៃកំណើត កំណត់ហេតុសកម្មភាព និងបម្រុងទុកក្នុងម៉ាស៊ីន
- Light mode និង Dark mode

## គ្រោង Database

`database.sql` មាន MySQL schema សម្រាប់ភ្ជាប់ជាមួយ Laravel backend។ តារាងសំខាន់ៗរួមមាន៖

- `students`
- `teachers`
- `classes`
- `certificates`
- `users`
- `academic_years`
- `promotions`
- `school_settings`
- `school_events`
- `activity_logs`
- `database_backups`

Composer មិនមាននៅក្នុងបរិស្ថាននេះទេ ដូច្នេះ workspace នេះមាន Frontend prototype ពេញលេញ និង Database schema ជំនួស Laravel Breeze project ដែលបាន scaffold។
